# R&R Holdings & Ventures LLC

Official corporate website for R&R Holdings & Ventures LLC.

Static website for GitHub Pages. In Settings > Pages, select Deploy from a branch, main, / (root).

Before launch: replace contact and support email notices with verified business email links; review draft privacy and terms pages; add app-specific privacy policy and support details; confirm corporate name and copy. No analytics, forms, external fonts or JavaScript are included.

Preview locally: python -m http.server 8000, then open http://localhost:8000.
